# Recipe Search – Flask + MySQL + TheMealDB

Een webapplicatie in Flask waarmee je gerechten kunt zoeken op basis van ingrediënten
via **TheMealDB API**, en deze vervolgens kunt **opslaan, bekijken, bewerken en verwijderen**
in een **MySQL-database**.
